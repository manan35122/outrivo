# Outrivo Web

Planned pages (Next.js, deployed on Vercel):

- `/` customer page: landing + chat with the agent (sends `user_id` and `thread_id` to `POST /chat`)
- `/admin` admin dashboard: leads, pipeline stages, outreach drafts, usage

Set `NEXT_PUBLIC_AGENT_API_URL` to the agent API base URL.
